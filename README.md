## Start here

1. Download/unzip the course repository. Check the official SWDA free-subscription course label and eligibility; redemption follows eligible attendance and is separate from agent/API access.
2. Use [Activity 1](labs/lab01-always-on-personal-assistants/README.md) to set up one accessible Muse, Dots or Grok Bot. Muse is recommended in Singapore: [iOS](https://apps.apple.com/sg/app/muse-from-meta/id6760173601) · [Android](https://play.google.com/store/apps/details?gl=sg&id=com.facebook.aura) · [Web](https://muse.ai). Verify the official developer and actual Gmail/Calendar connectors.
3. After lunch, [Activity 2](labs/lab02-hermes-desktop-skills/README.md) introduces the company scenario and [Hermes Desktop](https://hermes-agent.nousresearch.com/desktop). Review/install the five course skills and verify the native tools.
4. Follow steps in order and keep documented output paths. Native Windows learners use the supplied PowerShell guide; Desktop and WSL use separate paths/credentials. Preserve existing AGENTS.md.
5. Inspect actual saved artifacts and source records. Skills describe procedures; gog, Python and FFmpeg execute tools. They are not extra agents.

## Practical evidence

PP Task 2: **ONE professional PPT image** (Activity 4), with actual skills/tools evidence retained. PP Task 3: **ONE actual Kanban video-team image with Hermes bots** (Activity 5/8).
